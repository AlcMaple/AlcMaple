## 主要项目

### [MapleTools](https://github.com/AlcMaple/tools) · 追番管理 + 动漫聚合下载（Windows / macOS / 网页）

想找一个**能管理自己追番记录、又能直接看和下载动漫**的工具？MapleTools 就是为此做的：

- 聚合 **稀饭动漫（Xifan）、Girigiri 爱动漫、嗷呜** 搜索，选集在线观看或批量下载（多线程、断点续传、线路切换）
- **个人追番管理**：追番列表、观看进度、新番周历，Bangumi 番剧资料与评分
- 本地番剧媒体库扫描管理，**坚果云 WebDAV** 同步追番数据
- 桌面版下载：[Releases](https://github.com/AlcMaple/tools/releases) · 网页版：[anime.alcmaple.cn](https://anime.alcmaple.cn/)
